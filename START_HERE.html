nama_DL

v1.11.0 · Windows 10/11 x64 · Brave / Chrome

動画・音声・サムネイルを、動画一覧・プレイヤー・Xの共有ボタン横から保存する拡張機能です。

初めて使う方旧版からの更新使い方動かないとき
FIRST SETUP

初めて使う方

  1. ZIPを右クリックして「すべて展開」。展開した nama_DL フォルダーを、移動しない場所に置きます。
  2. Braveでは brave://extensions、Chromeでは chrome://extensions をアドレス欄に入力して開きます。
  3. 「デベロッパーモード」をONにし、「パッケージ化されていない拡張機能を読み込む」を押します。
  4. nama_DL の中の extension フォルダーを選びます。
  5. ツールバーからnama_DLを開き、「初回セットアップ・接続確認」→「IDをコピー」を押します。
  6. Setup.cmdをダブルクリックし、コピーしたIDを貼り付けてEnter。
  7. Setup complete と表示されたら完了。拡張機能とPC側のバージョンが両方 1.11.0 になっていることを確認します。
  8. サイトへのアクセス許可が出たら許可し、開いている動画・リストのページを再読み込みします。
必要ソフトは自動で取得します。自分でPython等を導入する必要はありません。初回はネット接続と数百MBの空き容量が必要です。

受け取った方それぞれの拡張機能IDを登録します。配布元のIDを入力する必要はありません。

UPDATE

旧版からの更新

  1. 処理が終わったら、拡張機能を一度OFFにします。
  2. 新しい nama_DL フォルダーの中身を、以前のフォルダーへ上書きします。以前のフォルダー名や場所は変えません。
  3. ApplyUpdate.cmdを実行します。
  4. 拡張機能をONにして再読み込み。必要ならサイトアクセスを許可します。
  5. 動画一覧・動画・リストのページもF5で再読み込みしてください。
保存先や形式の設定は引き継がれます。フォルダー移動でIDが変わった場合は、Setup.cmdで新しいIDを登録します。

保存する

動画一覧のカード、プレイヤー下部、マイリストの見出し、再生リストの三点メニュー横に追加されるダウンロードアイコンを押します。ツールバーのnama_DLからも同じ操作ができます。

動画を保存MP4 · 取得できる最高画質からAE用に変換
音声のみを保存WAV · 非圧縮24bit PCM
サムネイルのみを保存PNG · 画像だけを保存

保存先と詳細設定

保存先の「変更」でフォルダーを選びます。ログイン情報、サムネイル・メタデータの埋め込み、リスト全体保存は「詳細設定」にあります。

動画一覧のボタンは、その動画1本が対象です。動画ページへ移動せず、いつものメニューから保存できます。リストのページや再生リストのカードから押した場合は、そのリスト全体が対象です。ファイルはタイトル名で保存し、同名があれば連番を付けます。

メニューを閉じても処理は続きます。ブラウザー本体は開いたままにしてください。

対応するH.264/AACは再圧縮せずMP4へ保存します。変換が必要な動画は高品質設定で再圧縮します。元MKVは確認成功後に削除します。WAVは容量が大きめです。詳細は「はじめに.txt」を確認してください。

HELP

動かないとき

CheckSetup.cmdを開くと、必要ソフト・登録ID・PC側のバージョンを確認できます。確認結果を外部へ送る機能はありません。

  • 接続エラー：拡張機能IDが一致しているか確認し、必要ならSetup.cmdを再実行。
  • 古いバージョン：ApplyUpdate.cmdを実行し、拡張機能とページを再読み込み。
  • ボタンが見えない：サイトアクセスを許可してF5。ツールバーのnama_DLからも保存できます。
  • 取得エラー：Update.cmdでyt-dlpを更新して再試行。エラー文と対象URLを確認してください。

保存済みのMKVをMP4にする場合はConvertToMP4.cmd、PC側の削除はUninstall.cmdを使います。完成済みの保存ファイルは削除しません。

X（Twitter）：動画付き投稿の共有ボタン横のダウンロードアイコンを押します。1投稿に動画が複数ある場合は、各動画を保存します。必要に応じて詳細設定でログイン情報の使用をONにしてください。
